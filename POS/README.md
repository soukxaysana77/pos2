# Universal POS

ระบบ POS สำหรับธุรกิจหลายรูปแบบ เลือกได้หลายประเภทพร้อมกัน (เช่น รีสอร์ท + ร้านอาหาร + รถเช่า)

| กลุ่ม | ตัวอย่างธุรกิจ | สิ่งที่ระบบทำให้ |
|---|---|---|
| ขายสินค้า & อาหาร | มินิมาร์ท, ร้านอาหาร, คาเฟ่, ผับ/บาร์, เสื้อผ้า, ร้านยา, ของสด | ขายหน้าร้าน, บาร์โค้ด, สินค้าหลายแบบ/ชั่งน้ำหนัก, เปิดโต๊ะ–เช็คบิล |
| ที่พัก | โรงแรม/รีสอร์ท, บ้านพัก/พูลวิลล่า, โฮสเทล, ลานกางเต็นท์, หอพัก/อพาร์ทเมนต์ | เช็คอิน–เช็คเอาท์, คิดรายคืน/รายเดือน, ราคาวันศุกร์–เสาร์, ค่าเช็คเอาท์ช้า, มัดจำ, จองล่วงหน้า |
| ให้เช่า | รถเช่า, มอเตอร์ไซค์/จักรยาน, อุปกรณ์/ชุด/กล้อง | ปล่อยเช่า–รับคืน, รายวัน + ค่าเกินเวลา, มัดจำ, เลขไมล์/ใบขับขี่ |
| คิดเงินตามเวลา | KTV, สนุกเกอร์, สนามกีฬา, ร้านเกม/Co-working, ห้องประชุม, นวด/สปา, ที่จอดรถ | จับเวลาอัตโนมัติ, ราคาตามช่วงเวลา, ขั้นต่ำ/ปัดเศษเวลา, สั่งของเข้าห้อง/โต๊ะ |
| บริการ & รับงาน | ร้านซ่อม, ซักรีด, สั่งทำ/ตัดเย็บ, ร้านทำผม | ใบรับงาน, สถานะงาน, นัดรับ, มัดจำ, ส่งมอบพร้อมคิดเงิน |

ถ้าไม่เจอธุรกิจของคุณ เลือก **"อื่น ๆ ที่คิดตามเวลา / ให้เช่า"** แล้วตั้งชื่อ หน่วย และวิธีคิดเงินเองได้ทั้งหมด
(คิดได้ 6 แบบ: รายชั่วโมง, รายคืน, รายวัน, รายเดือน, เหมาต่อครั้ง, ไม่คิดเวลา + คิดต่อคนได้)

## ติดตั้ง (ครั้งเดียว)

1. ดับเบิลคลิก **`Install.cmd`** (ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ)
2. รอข้อความ "ติดตั้งเรียบร้อยแล้ว" แล้วหน้าขายจะเปิดขึ้นมาเอง
3. ครั้งแรกจะมี **ตัวช่วยตั้งค่าร้าน** ถาม 4 ข้อ: ชื่อร้าน, ประเภทร้าน, VAT/พร้อมเพย์ และจะเริ่มแบบร้านว่างหรือลองกับสินค้าตัวอย่าง

หลังติดตั้ง:
- เปิดโปรแกรมจากไอคอน **Universal POS** บนเดสก์ท็อปหรือเมนู Start
- โปรแกรมเปิดเองอัตโนมัติเมื่อเปิดเครื่อง
- โปรแกรมทำงานอยู่ที่ **ไอคอนมุมขวาล่างของจอ** (ข้างนาฬิกา) ไม่มีหน้าต่างดำ
  - ดับเบิลคลิกไอคอน = เปิดหน้าขาย
  - คลิกขวา = เมนู (เปิดโฟลเดอร์ข้อมูล, ให้เครื่องอื่นเชื่อมต่อ, พิมพ์ใบเสร็จทันที, เปิดพร้อม Windows, ปิดโปรแกรม)
- ถอนการติดตั้งได้ที่ Windows **Settings → Apps → Installed apps → Universal POS** (ข้อมูลร้านจะเก็บไว้ให้ เว้นแต่เลือกลบ)

### ติดตั้งเครื่องอื่น

บนเครื่องนี้รัน `tools\build-dist.ps1` จะได้ไฟล์ `dist\UniversalPOS-Setup.zip` (มี Node.js ในตัว เครื่องปลายทางไม่ต้องติดตั้งอะไรเพิ่ม)
นำไปแตกไฟล์ (Extract All) ที่เครื่องปลายทาง แล้วดับเบิลคลิก `Install.cmd`

```
powershell -ExecutionPolicy Bypass -File tools\build-dist.ps1
```

## ห้อง / โต๊ะ / รถ (เมนูผัง)

- **ผังสถานะ:** สีบอกสถานะ — ว่าง, ใช้งาน, เกินกำหนด, จองวันนี้, รอทำความสะอาด, ปิดปรับปรุง พร้อมเวลาที่ใช้ไปและยอดเงินถึงตอนนี้
- **แตะหน่วยที่ว่าง** → เช็คอิน / ปล่อยเช่า / เปิดโต๊ะ (ใส่ลูกค้า เวลา มัดจำ ข้อมูลเพิ่มเติม เช่น เลขบัตร ทะเบียนรถ เลขไมล์)
- **แตะหน่วยที่มีลูกค้า** → เปิดบิลในหน้าขาย เพิ่มรายการ (มินิบาร์ อาหาร เครื่องดื่ม) ค่าเวลาคำนวณให้อัตโนมัติ
- ในบิลมีปุ่ม **รายละเอียด** (แก้เวลา ขยายเวลา ราคาพิเศษ รับมัดจำเพิ่ม ยกเลิก), **ย้าย**, **ใบแจ้งยอด**, **เก็บเงินถึงตอนนี้** (สำหรับพักยาว/หอพักรายเดือน)
- **เช็คเอาท์:** หักมัดจำอัตโนมัติ ถ้ามัดจำเกินยอดจะบอกยอดที่ต้องคืนลูกค้า
- **จัดการ / ราคา:** แก้ชื่อ กลุ่ม (เช่น ห้องดีลักซ์) วิธีคิดเงิน เวลาเช็คอิน–เอาท์ ราคาตามช่วงเวลา มัดจำเริ่มต้น

## การจองล่วงหน้า & งานรับ

- **ปฏิทินการจอง:** มุมมองรายวัน (ที่พัก รถเช่า) และรายชั่วโมง (KTV สนาม ห้องประชุม) แตะช่องว่างเพื่อจอง ระบบกันจองซ้อน
- **รายการจอง:** ดูคนที่จะเข้าวันนี้ เช็คอินจากการจอง (มัดจำย้ายเข้าบิลอัตโนมัติ) ยกเลิก/ไม่มาตามนัด → เลือกคืนหรือไม่คืนมัดจำ
- **งานรับ:** รับงาน → พิมพ์ใบรับงาน → กำลังทำ → เสร็จรอรับ → ส่งมอบ & ชำระ (หักมัดจำให้อัตโนมัติ)

## เปิด–ปิดกะ (นับเงินในลิ้นชัก)

- ก่อนขายบิลแรก ระบบจะให้ **เปิดกะ**: ใส่ชื่อพนักงานและเงินทอนในลิ้นชัก
- ระหว่างวันบันทึก **นำเงินเข้า/ออก** ได้ เช่น แลกเหรียญ, จ่ายค่าน้ำแข็ง
- ตอน **ปิดกะ** ให้นับเงินตามชนิดธนบัตร/เหรียญ แล้วระบบจะบอกว่าเงิน **ขาด/เกิน** เท่าไร และพิมพ์ใบสรุปกะได้
- ดูประวัติกะย้อนหลังได้ที่ **ประวัติขาย → กะ & ลิ้นชักเงินสด**
- ร้านที่ไม่ต้องการใช้ ปิดได้ที่ **ตั้งค่า → ใช้ระบบเปิด–ปิดกะ**

## ข้อมูลร้าน & การสำรองข้อมูล

ข้อมูลร้านบันทึกอัตโนมัติที่ `%LOCALAPPDATA%\UniversalPOS\data\pos-data.json`
(เปิดโฟลเดอร์ได้จากเมนูที่ไอคอนมุมจอ หรือ ตั้งค่า → การจัดเก็บข้อมูล → เปิดโฟลเดอร์ข้อมูล)

ไฟล์สำรองอัตโนมัติอยู่ในโฟลเดอร์ `backups`
- `hourly-*`: รายชั่วโมง เก็บ 48 ไฟล์ล่าสุด
- `daily-*`: รายวัน เก็บ 90 วัน
- `manual-*`: สำรองก่อนนำเข้าข้อมูล โหลดข้อมูลตัวอย่าง รีเซ็ต หรือกู้คืน (เก็บ 30 ไฟล์)

กู้คืนได้จากหน้า **ตั้งค่า → การจัดเก็บข้อมูล → ไฟล์สำรองอัตโนมัติ**
แนะนำให้คัดลอกโฟลเดอร์ข้อมูลไปเก็บไว้ที่อื่นด้วยเป็นระยะ (แฟลชไดรฟ์, Google Drive, OneDrive)

### ข้อมูลตัวอย่าง

ถ้าเลือก "ลองใช้กับสินค้าตัวอย่าง" จะมีแถบสีเหลืองบนหน้าขาย เมื่อพร้อมใช้จริงกด **ลบข้อมูลตัวอย่าง**
ระบบจะลบเฉพาะสินค้า ลูกค้า ยอดขาย และกะที่เป็นตัวอย่าง สินค้าที่คุณเพิ่มเองจะยังอยู่

## ใช้หลายเครื่องในร้าน

คลิกขวาที่ไอคอนมุมจอ → **ให้เครื่องอื่นในร้านเชื่อมต่อได้** ระบบจะแสดงที่อยู่ เช่น `http://192.168.1.10:8080`
ให้แท็บเล็ตหรือมือถือที่ต่อ Wi-Fi วงเดียวกันเปิดที่อยู่นั้น ทุกเครื่องจะใช้สินค้า สต็อก และยอดขายชุดเดียวกัน
แต่ละเครื่องเปิด–ปิดกะของตัวเอง (1 เครื่อง = 1 ลิ้นชัก)
(ครั้งแรก Windows อาจถามเรื่อง Firewall ให้กด "อนุญาต" สำหรับเครือข่ายส่วนตัว)

> ⚠ โหมดนี้ใครที่ต่อ Wi-Fi เดียวกันก็เปิดข้อมูลร้านได้ ใช้เฉพาะเครือข่ายของร้าน อย่าใช้บน Wi-Fi สำหรับลูกค้า

### ถ้าการเชื่อมต่อหลุด

ขายต่อได้ตามปกติ ป้ายสถานะจะแสดง "ออฟไลน์" ระหว่างนั้นข้อมูลเก็บชั่วคราวในเบราว์เซอร์
เมื่อเชื่อมต่อได้อีกครั้ง ระบบจะบันทึกลงไฟล์ให้อัตโนมัติ และรวมข้อมูลกับเครื่องอื่นให้ (รวมถึงยอดสต็อกและแต้มสะสม)

## พิมพ์ใบเสร็จทันที (ไม่ต้องกดยืนยัน)

1. ตั้งเครื่องพิมพ์ใบเสร็จเป็น **เครื่องพิมพ์หลัก (Default printer)** ของ Windows
2. คลิกขวาที่ไอคอนมุมจอ → **พิมพ์ใบเสร็จทันทีโดยไม่ต้องกดยืนยัน**
3. ปิดหน้าขายแล้วเปิดใหม่ และเปิด ตั้งค่า → **พิมพ์ใบเสร็จอัตโนมัติ** ด้วย ถ้าต้องการให้พิมพ์ทุกบิล

## สำหรับนักพัฒนา

รันโดยไม่ติดตั้ง: `start-pos.bat` (ข้อมูลอยู่ในโฟลเดอร์ `data` ข้างโปรแกรม)
ตอนติดตั้งด้วย `Install.cmd` ข้อมูลในโฟลเดอร์ `data` นี้จะถูกย้ายไปให้อัตโนมัติ

ถ้าเปิด `start-pos.bat` ซ้ำขณะที่เปิดอยู่แล้ว โปรแกรมจะไม่เปิดซ้อน แต่จะเปิดหน้าขายของตัวเดิมให้แทน

**เริ่มต้นใหม่ทุกอย่าง:** `restart-pos.bat` — ล้างข้อมูลร้านทั้งหมด (สินค้า บิล ลูกค้า กะ ห้อง การจอง งานรับ การตั้งค่า)
แล้วเปิดโปรแกรมใหม่พร้อมตัวช่วยตั้งค่าร้าน เหมือนเพิ่งติดตั้ง ต้องพิมพ์ `reset` เพื่อยืนยันก่อน
- ข้อมูลเดิมไม่ได้ถูกลบ — ย้ายไปเก็บที่ `data\reset-backup-วันที่เวลา` (ลบโฟลเดอร์นั้นเองได้ถ้าไม่ต้องการแล้ว
  หรือคัดลอก `pos-data.json` ในนั้นกลับมาวางแทนไฟล์ใน `data` ถ้าต้องการย้อนกลับ ขณะปิดโปรแกรมอยู่)
- ทุกเบราว์เซอร์/แท็บเล็ตที่เคยเชื่อมต่อจะล้างสำเนาร้านเดิมของตัวเองอัตโนมัติ ไม่ส่งข้อมูลเก่ากลับขึ้นมา
- ถ้าเดิมเปิดแบบให้เครื่องอื่นเชื่อมต่อ จะเปิดกลับมาแบบเดิม
- ใช้กับโปรแกรมที่เปิดจาก `start-pos.bat` เท่านั้น (แบบติดตั้งด้วย `Install.cmd` ใช้ปุ่ม ตั้งค่า → "เริ่มต้นใหม่ (ลบข้อมูลทั้งหมด)" ในหน้าโปรแกรมแทน)

```
node server.js --port 9000              # เปลี่ยนพอร์ต (ค่าเริ่มต้น 8080)
node server.js --data D:\POS-Data       # เก็บข้อมูลไว้ที่โฟลเดอร์อื่น
node server.js --lan                    # เปิดให้เครื่องอื่นในเครือข่ายเข้าใช้
node server.js --log server.log         # เขียน log ลงไฟล์
```
